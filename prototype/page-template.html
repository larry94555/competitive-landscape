The recording has no audio. Subtitles are on by default, so it reads fine muted. Narration is optional and spoken by your browser — and it sets the pace: the video pauses while each line is read, then continues, so nothing is cut off mid-sentence.

This is a prototype, not the product. Invented companies on the reserved .example domain, no working system behind it, throwaway code. It exists to answer one question before any production code is written: does a 90–180 second wait read as work happening, or as a hang?
