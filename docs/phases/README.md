# Phase checklists — what only you can do

> **These pages list the actions that are yours.** Not the whole roadmap — the specific
> things that cannot be done by an agent, in order, with what "done" looks like and how it
> gets verified.
>
> [ROADMAP.md](../ROADMAP.md) is the plan. These are the parts of it with your name on them.

Every step on these pages has the same five fields, so you can start one without reading
around it:

| Field | Means |
|---|---|
| **Do** | The action, in one sentence |
| **Where** | The URL, console or file. Clickable |
| **Time** | An honest estimate, not an encouraging one |
| **Done when** | The observable state that ends the step |
| **I confirm by** | Exactly what I check, and what I write down when it passes |

**"I confirm by" is the important column.** Where it says *automatically*, I can check the
claim myself — a DNS record exists, a file is in the repository, a test passes. Where it says
*you tell me*, I am taking your word and recording it, which is the honest description of a
conversation with a founder that I was not part of.
